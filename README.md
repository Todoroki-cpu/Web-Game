# 🌟 わくわく まなびらんど (iPad知育ゲーム)

iPadのタッチ操作に最適化した、子ども向け知育Webゲームです。

## 🎮 収録ゲーム（全12種類）

### 🔢 すうじ（数字）
1. **🍎 もぐもぐ お買い物** - かずを数えておさらに運ぶ（1〜5）
2. **✨ すうじ てんつなぎ** - 1から順につないでイラスト完成（1〜10）
3. **🎈 バブルポップ** - 大きい数・小さい数のシャボン玉をタッチ
4. **🪙 10円 おかいもの** - 10円と1円の位取り（10〜99円）
5. **🚀 10とび ロケット** - 10, 20, 30... 100で月へ発射
6. **🎯 すうじの 的あて** - 2桁の数字の大小比較

### ⏰ とけい（時計）
7. **🕰️ ぐるぐる とけい** - 時計の針を回して生活時間を合わせる
8. **⏱️ とけい ぴったりマッチ** - デジタルとアナログ時計のペア合わせ

### 📅 ようび（曜日）
9. **🚂 1しゅうかん トレイン** - 月〜日の曜日列車を連結
10. **🗓️ ようび カレンダー** - ヒントから曜日を当てることばあそびクイズ

### 🌸 きせつ（季節）
11. **👗 きせつの アイテム集め** - 春夏秋冬の風物詩をカゴに集める
12. **🔄 めぐる まほうの木** - 季節ダイヤルを回して木を変身させる

---

## 🎙️ 音声について
PC上の **VOICEVOX** を使用して、4人のキャラクター（ずんだもん、玄野武宏、四国めたん、春日部つむぎ）の音声を高音質収録しています。
GitHub Pages上で完全オフライン・遅延ゼロで再生可能です。
