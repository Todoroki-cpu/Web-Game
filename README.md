# 🌟 わくわく まなびらんど (iPad知育ゲーム)

iPadのタッチ操作に最適化した、子ども向け知育Webゲームです。

## 🎮 収録ゲーム（全15種類・5大カテゴリ）

### 🔢 すうじ（数字）
1. **🍎 もぐもぐ お買い物** - かずを数えておさらに運ぶ（1〜5）
2. **✨ すうじ てんつなぎ** - 1から順につないでイラスト完成（1〜10）
3. **🎈 バブルポップ** - 大きい数・小さい数のシャボン玉をタッチ
4. **🪙 10円 おかいもの** - 10円と1円の位取り（10〜99円）
5. **🚀 10とび ロケット** - 10, 20, 30... 100で月へ発射
6. **🎯 すうじの 的あて** - 2桁の数字の大小比較

### 🔤 ひらがな（サンリオ風キャラクター）
7. **✨ ひらがな なぞり書き** - ガイドに沿って虹色キラキラストロークで書き順学習（シナモン風）
8. **🎪 キャラクター かるた** - 読まれた文字をパチンとタッチして絵カードへ変身（キティ風）
9. **🍱 ことばの もぐもぐパズル** - 文字をならべてごちそうを作りプリンにあげるパズル（プリン風）

### ⏰ とけい（時計）
10. **🕰️ ぐるぐる とけい** - 時計の針を回して生活時間を合わせる
11. **⏱️ とけい ぴったりマッチ** - デジタルとアナログ時計のペア合わせ

### 📅 ようび（曜日）
12. **🚂 1しゅうかん トレイン** - 月〜日の曜日列車を連結
13. **🗓️ ようび カレンダー** - ヒントから曜日を当てることばあそびクイズ

### 🌸 きせつ（季節）
14. **🧺 きせつの アイテム集め** - 春夏秋冬の風物詩をカゴに集める
15. **🌳 めぐる まほうの木** - 季節ダイヤルを回して木を変身させる

---

## 🎙️ 音声とキャラクターについて
PC上の **VOICEVOX** を使用して、各キャラクター専用の個別音声を事前高音質合成・収録しています。
- **アンパンマン風**: アンパン風（ずんだもん）、ばいきん風（玄野武宏）、しょくぱん風（四国めたん）、メロンパン風（春日部つむぎ）
- **サンリオ風**: キティ風（四国めたん あまあま）、シナモン風（春日部つむぎ）、プリン風（ずんだもん あまあま）、メロディ風（雨晴はう）

GitHub Pages上でサーバー依存ゼロ・完全オフライン・低遅延で再生可能です。
